what gets sent
It disguises your stolen password until it reads as empty text, then sends it out over a connection built to trust any server, even a fake one. Your Mac normally refuses to send data to a site it cannot verify. This skips that check, so the theft travels like ordinary, trusted traffic and nothing looks wrong.
⟩DHow it hides once it is in
Disguise

Runs as cloudsync, so in your Mac's list of running programs it looks like a harmless sync tool.

Tucks the stolen data into a hidden folder you would never think to open.
Evasion

Antivirus knows bad files by a fingerprint. This keeps rewriting itself so its fingerprint never matches.
